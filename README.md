# FINANCE GEN AI
### Generative AI-Based Financial Statement Analysis System

## About the Project
FINANCE GEN AI is a financial chatbot that allows users to ask questions about company financial data in simple English. It retrieves relevant information from a financial CSV dataset and uses an AI language model to generate understandable answers.

## Features
- Ask questions about company financial statements.
- Retrieve financial information by company and year.
- Analyze metrics such as revenue, net income, and cash flow.
- Generate answers using Llama 3.2.
- Interactive web interface.

## Technologies Used
- Python
- Pandas
- Streamlit
- Ollama
- Llama 3.2
- CSV Dataset

## Dataset
The dataset contains financial information for 12 companies from 2009 to 2023, with 161 records.

It includes metrics such as:
- Revenue
- Gross Profit
- Net Income
- EBITDA
- Cash Flow
- Market Capitalization
- ROE
- ROA

## How It Works
1. Upload the financial CSV dataset.
2. Ask a question about a company.
3. The system retrieves the relevant financial information.
4. Llama 3.2 helps generate a clear answer.
5. View the answer in the Streamlit interface.

## How to Run
1. Install Python.
2. Install the required Python packages.
3. Install Ollama and download the Llama 3.2 model.
4. Open the project folder in the terminal.
5. Run the Streamlit application.

## Note
Answers depend on the information available in the uploaded dataset.
